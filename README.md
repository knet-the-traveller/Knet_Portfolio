## About

This is the personal portfolio and web resume of **Mark Kenneth Galario**, a BSIT student at the Polytechnic University of the Philippines (PUP), Manila, and a DOST Scholar. It showcases hackathon results, projects, leadership experience in tech communities, and education.

The site was built as a Responsive Web Design activity, using only HTML, CSS, and vanilla JavaScript, with no frameworks or libraries.

## Sections

- **Home**: introduction, short bio, and social links
- **Highlights**: key achievements at a glance
- **Hackathons & Competitions**: eGOVPH Top 5 Finalist, KPMG Academic Innovation Challenge Top 5 Finalist, ENEDA 2nd Place, and more
- **Projects**: eGuide, ARWays, Claro, RILES, and AgriTayo, each with a live demo link
- **Experience**: leadership and operations roles in student tech organizations
- **Education**: PUP, DOST Scholarship, and Sapang Palay National High School
- **Photo Gallery**: event photos with a full-screen lightbox viewer
- **Contact**: email, phone, location, and social links

## Features

- Fully responsive, mobile-first layout (tested from small phones to large desktop screens)
- Dark and light theme toggle that remembers your choice
- Sticky navigation with scroll-spy and a mobile hamburger menu
- Scroll-triggered reveal animations and animated highlight counters
- Accessible photo lightbox with keyboard and swipe navigation
- Expandable experience timeline
- Print-friendly stylesheet for a clean printed resume
- Respects `prefers-reduced-motion` and includes keyboard and screen-reader support

## Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/knet-the-traveller/knet_portfolio.git
   ```
2. Open the folder and double-click `index.html`, or serve it with a local server such as the VS Code **Live Server** extension.

No build step or dependencies are required.
